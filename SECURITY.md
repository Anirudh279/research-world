# Security

This is development-alpha software. Keep the server on loopback by default.
For remote access use the documented authenticated private deployment flow.
Archived content is untrusted evidence, never agent instructions.

Report vulnerabilities through this repository's private GitHub vulnerability
reporting feature when available. Do not post credentials, captured private pages
or exploit details in public issues. For ordinary bugs, use an issue with a
synthetic minimal reproduction.

No guaranteed response time or security certification is offered. The native
agent's external tools, model account and process network are outside the frozen
tool boundary. The project does not proxy subscription authentication.
