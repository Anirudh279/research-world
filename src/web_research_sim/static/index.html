  1. Keep this workspace server running.
  2. Register the local bridge in your agent. Replace the example path with your installation.
codex mcp add research-world -- /absolute/path/to/web-research-sim/.venv/bin/python -m web_research_sim.mcp_server --mode all

For Claude Code, the registration command is:

claude mcp add --transport stdio research-world -- /absolute/path/to/web-research-sim/.venv/bin/python -m web_research_sim.mcp_server --mode all

Set WR_SIM_URL and, if required, WR_SIM_TOKEN in the bridge's private environment. Keep your model account signed in through its own app. Do not paste subscription credentials here.

Ask your agent:

“Create a research world for my question. Use your own web search, save the source URLs with live_capture_discovered, then freeze the world. Start a native session, research with that session's frozen tools, and submit an answer with exact source quotes. Do not call hosted research or hosted collection.”

Then refresh Worlds here to inspect the captures and saved run. For comparisons, pin the bridge to the saved snapshot with --snapshot SNAPSHOT_ID and use its default frozen mode. Disable other web tools separately: the bridge does not isolate the whole agent or erase its prior knowledge.

Native account eligibility, limits and charges still apply. These smoke runs do not establish compatibility with every subscription. Browser-only chat services cannot run this local bridge. The all mode also exposes separately billed hosted tools; use only the tools you intend.
