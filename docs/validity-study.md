# What our first validity study established

This is a public summary of a private, bounded study performed on 15–16 October 2026. It is not a peer-reviewed paper or an independently reproducible public dataset. Original publisher captures, account logs and internal receipts remain private. The repository's [Mossbank example](../examples/mossbank/README.txt) is a separate, redistributable reproduction exercise.

**Question:** What is the difference between UTC and TAI, and why are leap seconds used?

**Evidence:** two captured NIST pages. **Configurations:** concise research versus explicit cross-source examination, using the same native client configuration and a limit of 12 recorded tools per trial. Actual served model identity and monetary subscription cost were unverified.

Expected outcomes and invalidating findings were recorded before eight fresh trials. Four submitted answers; four stopped after invalid searches. A narrowly scoped tool-description fix was followed by a separately registered baseline pair, both of which submitted answers. The failed trials were retained.

| Check | Observation | Limit |
|---|---|---|
| Independent reconstruction | All six fresh submitted metric rows reproduced from bytes, observations and ledgers | Same local records; not provider attestations |
| Temporal boundary | Tested later capture, asset and search event excluded from earlier snapshot | Does not remove training knowledge |
| Source removal | Partial answer acknowledged missing TAI construction evidence | Other strategy had no answer |
| Contradiction | Submitted answer identified the synthetic conflict | Clearly synthetic, not sophisticated misinformation |
| Search order | Main scientific claims remained supported | One trial cannot separate order effects from sampling |
| Corruption | Product and independent verifier rejected changed bytes | Bounded artifact test |
| Blinded model review | Scientific claims in submitted answers supported by archived evidence | Not human or live-fact validation |

The reviewer initially lacked tool descriptions and flagged an assertion about lexical search. A separately preserved supplement supported that assertion as a declared tool contract; actual client receipt and implementation were not independently verified by that reviewer.

A retrospective comparison also failed comparability: the collecting agent had seen live search results that the other agent had not. The same final snapshot was not enough to establish equal information.

The smallest production fix documented valid search arguments and clarified that search is not a list-all operation. It did not change retrieval behavior. We do not claim a causal improvement from one follow-up pair.

**Conclusion:** evidence access and measurements can be audited in this bounded setup. No model ranking, general robustness, forecasting skill or exhaustive collection claim follows. The public example can validate the mechanics; the private study's full result cannot be independently reproduced from this public repository alone.
